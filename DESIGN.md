# snag interface

Operate mode. Quiet light desktop workbench, dark ink, muted green accent, compact left navigation, spacious central queue, docked quality inspector. Korean system typography for legibility; tabular numbers for sizes and progress. Native window frame, keyboard-accessible labeled controls, visible focus, reduced-motion support. Empty state explains the actual Chrome-to-queue mechanism. Small drop window uses the same typography and accent. No decorative gradients or invented statistics. Astryx shell-side-nav frame and token-based component styles.

Motion references: DesignBookmark File drop, Loading to success, Step progress,
Segmented control, Morph island and Copy button. Links trigger drop feedback;
backend phases drive status and step transitions. Completion uses semantic success
tokens only after the completed event. The existing small window morphs internally
without changing native dimensions. Media selection uses Astryx's accessible sliding
control; clipboard confirmation follows a successful write. Custom soft/settle springs
run only during transitions and cancel when interrupted or reduced motion changes.
