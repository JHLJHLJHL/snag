SNAG beta 0.1.0 · Windows x64

실행하기
1. ZIP 파일을 원하는 폴더에 전부 압축 해제하세요.
2. SNAG(beta).exe를 실행하세요.
3. 영상 또는 재생목록 주소를 붙여넣고 대기열에 추가하세요.
4. 항목을 체크하고 영상 다운 또는 음성 다운으로 저장 형태를 정하세요.
5. 오른쪽 하단의 선택한 N개 다운로드를 눌러 저장을 시작하세요.

SNAG(beta).exe, engine, extension 폴더는 함께 보관하세요.
EXE만 따로 복사하거나 ZIP 안에서 바로 실행하면 정상 동작하지 않을 수 있습니다.
받는 PC에 Node.js, Rust, Python, FFmpeg를 따로 설치할 필요는 없습니다.

필요한 환경
- Windows 10/11, 64비트(x64)
- 인터넷 연결과 Microsoft Edge WebView2 Runtime
- WebView2가 없어서 실행되지 않으면 install 폴더의
  MicrosoftEdgeWebview2Setup.exe를 실행하세요. 설치에는 인터넷이 필요합니다.
- 공식 안내: https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution

크롬 연결은 선택 사항입니다
주소 붙여넣기만으로도 다운로드할 수 있습니다.
크롬에서 끌어다 놓기와 영상 감지 기능을 쓰려면:
1. SNAG에서 크롬 연결 → 크롬 연결 등록을 누르세요.
2. 크롬의 chrome://extensions 에서 개발자 모드를 켜세요.
3. 압축해제된 확장 프로그램을 로드합니다를 누르고 extension 폴더를 고르세요.
4. 영상 페이지를 새로고침하세요.
앱 폴더를 옮기면 연결 다시 등록을 눌러 주세요.

목록과 파일 정리
- 대기열의 제거: 선택한 항목만 목록에서 제외하며 파일은 지우지 않습니다.
- 완료 목록의 삭제: 기본적으로 완료 기록만 지웁니다.
- 파일도 함께 삭제를 체크하고 확인하면 실제 파일도 삭제합니다.
  이 파일 삭제는 휴지통을 거치지 않습니다.
- 대기열과 설정은 Windows 사용자 계정별로 로컬에 보관됩니다.

지원 범위
공개 영상과 재생목록을 대상으로 하는 베타 버전입니다.
로그인이 필요한 영상, DRM 보호 영상, 진행 중인 실시간 방송은 지원하지 않습니다.
모든 사이트의 동작을 보장하지 않으며 원본이 제공하는 품질 안에서 저장합니다.

SOURCE_LINKS.md를 참고하세요. 이 자료들은 배포본에 함께 보관해 주세요.
