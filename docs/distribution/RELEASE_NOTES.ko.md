# SNAG 0.1.0 beta

배포일: 2026-11-22 · Windows 10/11 x64 · 포터블 ZIP

- 영상·재생목록 주소를 대기열에 추가하고 순서대로 저장합니다.
- 체크한 항목을 영상(MP4) 또는 음성(MP3)으로 한 번에 설정합니다. 실제 저장은 오른쪽 하단 다운로드 버튼으로 시작합니다.
- MP3 출력 음질과 사이트가 제공하는 화질·음성 트랙을 선택할 수 있습니다.
- 전체 선택·해제, 순서 변경, 일시 정지, 재시도와 목록 제거를 제공합니다.
- 완료한 파일을 골라 DROP6 전송 창에 추가할 수 있습니다.
- 완료 기록을 정리하거나, 확인창에서 선택한 실제 파일까지 삭제할 수 있습니다.
- 크롬 확장 프로그램과 작은 드롭 창을 사용할 수 있습니다.
- 선택·작업 행은 고정되고 목록만 스크롤합니다.
