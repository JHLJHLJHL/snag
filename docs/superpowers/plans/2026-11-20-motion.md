## Global Constraints

No new runtime dependencies; preserve theme, layout frame, queue commands and native
window dimensions. No raw div/span or CSS imports; token-based dimensions and colors.
Animations must be interrupted cleanly and respect prefers-reduced-motion live changes.

## Review Focus

- Processing at 100% must remain busy and never report success.
- Completion history must not replay old success notices when mounted.
- MP3 and media mode changes must preserve the existing format invariants.
- Rejected clipboard writes must not display a success check.
- Native 310 by 210 drop window and 900-wide main window must not overflow.
